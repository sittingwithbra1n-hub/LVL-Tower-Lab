# LVL Tower Lab — версия 0.8

Локальный сайт для предварительного линейного статического МКЭ-расчёта пространственной стержневой башни из LVL на собственный вес и приближённую среднюю статическую составляющую ветра.

## Запуск на Windows

1. Распакуйте ZIP полностью в отдельную папку.
2. Убедитесь, что установлен Python 3.11/3.12 и `python --version` работает в `cmd`.
3. Запустите `run_windows.bat`. При первом запуске Python скачает зависимости, потребуется интернет.
4. Сайт откроется по адресу `http://localhost:8501`; не закрывайте окно командной строки.

## Новое в версии 0.8

- Подсказки у максимальных перемещений: кроме координат и номера узла показываются **все** КЭ, имеющие этот узел начальным или конечным. У одного узла может быть несколько примыкающих стержней, поэтому перечисляются все номера. Для моментов сохраняются номер определяющего КЭ, его конец и номер узла.
- В боковой панели выбора отображения добавлены шесть цветовых палитр: «Бирюза и янтарь», «Графит и медь», «Синий и серебро», «Лес и золото», «Фиолетовый и коралл», «Монохром». Цвета влияют только на 3D-визуализацию, не меняют расчёт.
- После вкладки «Подбор сечения» добавлена вкладка «Нужно доработать» с тематическими задачами и галочками. Список составлен по индивидуальному плану диссертации (приложение «План диссертации», главы 2–4), а также по формулировкам научных задач из документа «Кушнир аспирантура». Устойчивость, полный ветер, сравнение со SCAD и испытания на изгиб — дополнения для развития прототипа; изгиб помечен отдельно.
- Галочки хранятся в текущем сеансе Streamlit. Чтобы **не потерять их между перезапусками** и переносить с компьютера на компьютер, нажмите «Сохранить отмеченные задачи · JSON». Чтобы восстановить, загрузите файл на вкладке «Нужно доработать» и нажмите «Загрузить отметки».
- Отметка о выполнении — ручной чек-лист, а не автоматическое подтверждение расчёта или наличия экспериментальных данных.

## Изменения 0.7

### Изменения интерфейса в 0.7

- Кнопка «Показать координатную сетку»: выключенное состояние полностью скрывает фон, осевые линии, все подписи осей и числовые отметки X/Y/Z.
- Легенда под 3D-моделью скрыта, включая подписи «Человек 1,70 м», местные оси и другие условные обозначения. При этом переключатели показа человека, местных осей и закреплений продолжают работать.
- Убраны серые точки в серединах стержней. Выбор КЭ производится нажатием на сам стержень. Для расширения зоны нажатия поверх него используется почти прозрачная линия. Существует альтернативный ввод номера КЭ.
- Чтобы снять выбор, нажмите Esc при работе с 3D-окном или установите номер КЭ равным 0. Встроенный обработчик Esc зависит от того, передаёт ли браузер фокус окну модели.
- Рядом с максимумами перемещений и усилий выводится значок справки «?»: при наведении указан номер узла (для перемещения) или номер КЭ и его конца (для момента), значение со знаком. Для N показывается КЭ с максимальным по модулю усреднённым N; для моментов — максимальное значение на концах стержней.
- Собственный вес всегда включён. На вкладке «Нагрузки» выбирается, добавлять ли ветер к собственному весу. Переключатель «Показывать стрелки ветра на модели» влияет только на изображение и не изменяет расчёт.
- Условные ветровые стрелки теперь выбираются из нагруженных КЭ по высотам их середин; отображается до 12 стрелок. Реальная распределённая нагрузка рассчитывается для каждого КЭ независимо от количества видимых стрелок. Длина каждой стрелки относительна соответствующей погонной нагрузке и не является масштабной эпюрой по СП 20.


- Только два режима: «Загрузить схему из SCAD» и «Построить башню самостоятельно».
- При импорте SCAD TXT геометрия нормализуется: широкий нижний контур находится на Z=0 и жёстко закрепляется. Это **изменяет** исходные узловые координаты/опоры при необходимости и не эквивалентно исходному SCAD TXT без той же корректировки.
- При создании башни радиус нижнего кольца не меньше радиуса верхнего.
- «Поворот верхнего кольца» — угловое смещение верхних узлов относительно соответствующих нижних вокруг глобальной вертикальной оси Z. Это не угол наклона стержня: последний вычисляется отдельно.
- Удалено отображение деформированной схемы.
- Координатная сетка включается отдельно; отключены фоновые плоскости, подсказки-проекции и hover-метки осевых сеток (Plotly 3D). Координаты X и Y на оси не подписываются.
- Новая интерактивная 3D-модель: нажмите на наклонный или кольцевой стержень; открываются результаты КЭ. Есть надёжный альтернативный ввод «Номер конечного элемента».
- Местные оси: «Выкл», «Выбранного КЭ», «Всех КЭ». x₁ — вдоль элемента от начального узла к конечному, y₁ и z₁ — поперечные оси, выбранные нашим расчётным алгоритмом. Местные оси и положительные знаки моментов могут отличаться от SCAD из-за настройки ориентации.
- В панели результатов название «Деформации по X/Y/Z» означает узловые **перемещения**, мм. Можно увидеть перемещения начального и конечного узлов выбранного КЭ, N, Mx (изгиб вокруг z₁), My (изгиб вокруг y₁) и Mk (кручение вокруг x₁) отдельно для двух концов.
- Собственный вес учитывается **автоматически всегда**, а ветровые нагрузки прикладываются при включении «Учитывать ветер в расчёте». В режиме ветра при включённом отображении на схеме показаны условные голубые отрезки, а под результатами выбранного КЭ — компоненты распределённой нагрузки, кН/м.
- При изменении размеров сечения, E, ν, плотности, схемы и загружения **выполняется новый расчёт**. Подбор вариантов сечений в третьей вкладке запускается отдельно кнопкой «Рассчитать и подобрать».

## Ограничения

- 3D-клик реализован отдельным локальным Streamlit-компонентом с Plotly.js, который поставляется с архивом (не требует внешнего CDN). В среде сборки не было доступного Streamlit-браузера для проверки фронтенда на Windows; при проблемах с кликом используйте ввод номера КЭ.
- Сечения у всех стержней одинаковые (прямоугольник), материал в данном прототипе условно изотропный линейно-упругий.
- Пока одна семья прямолинейных образующих + кольцевые стержни; не полная перекрёстная решётка Шухова.
- **Это не нормативный ветровой расчёт башни по СП 20**: от СП использованы базовое давление w0 и высотный коэффициент k(z), а распределение нагрузки по стержням приближённое. Аэродинамическое затенение решётки, пульсационная составляющая, динамика, нормативные сочетания и проверка точного ветрового района для площадки не выполнены. Города являются предварительными подсказками и требуют проверки по карте приложения Е СП 20.
- Не учтены ортотропия LVL, геометрическая и физическая нелинейность, потеря устойчивости, податливость узлов, проверка креплений, устойчивость стержней при сжатии. Подбор сечений — только предварительный по условным пределам и массе.
- Расчётные результаты ещё не верифицированы сравнением с SCAD для той же схемы, опор и загружений.

## Структура проекта

- `app.py` — Streamlit UI и результаты;
- `fem.py` — линейный МКЭ и нагрузки;
- `scad_txt.py` — импорт узлов/стержней/закреплений из SCAD TXT;
- `tower_graph.py` — 3D-графика, местные оси, выделение КЭ;
- `tower_view.py` + `tower_picker/` — локальный компонент 3D-выбора стержня с Plotly.js;
- `verify.py` — тесты импорта и собственного веса;
- `sample/оболочка.txt` — тестовая исходная схема.

При проверке вычислительной части: `python verify.py`.
